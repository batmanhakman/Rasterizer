# Editable Gilded Warden source

`knight.blend` is the editable Blender project for the bundled reference-inspired knight. Open it to inspect the named armor components, cloth surfaces, articulated gloves and boots, materials, modifiers, studio camera, and lighting. Both `knight_atlas.png` and `knight_mail.png` are packed into the project. The saved viewport is framed on the figure.

The original geometry was authored as contour surfaces, fitted armor shells, lofted anatomical forms, and layered plate details. The design uses dark steel, narrow antique gold tracery, tan arming garments, and exposed chainmail. The figure is unarmed, with no cape, tabard, shield, or sword. The visual reference itself is not distributed in this repository.

The Blender scene uses Z-up, with the knight facing negative Y. Its OBJ export uses Y-up and faces negative Z, matching the viewer's import convention. The runtime OBJ, MTL, and two PNG textures are in `../assets/knight/`.

## Regenerate the project and export

From the repository root, with Blender on PATH:

```powershell
blender --background --python tools/create_knight_blender.py
python tools/validate_knight.py
```

Replace `blender` with the full path to the installed executable if needed. The builder uses the modules in `tools/knight_parts/`:

| Module | Contents |
| --- | --- |
| `common.py` | Mesh helpers, material definitions, texture inputs, and shared scene collection |
| `body.py` | Pointed cuirass, traced gorget, domed pauldrons, girdle, tassets, and mail |
| `helmet.py` | Closed ornate helmet, crest, visor, and gold tracery |
| `limbs.py` | Relaxed arms, layered forearm armor, articulated hands, fitted leg armor, and sabatons |

The builder saves the editable project, exports triangulated geometry with independent position/UV/normal indices, and renders previews. The two generated texture images are source inputs and are not regenerated by the Blender script. Their provenance and generation prompts are recorded in [texture notes](../assets/knight/texture-prompts.md).

Blender is needed only to edit or regenerate the asset. Building and running the rasterizer does not require it. This is a static display model with separate editable surfaces; no character rig or animation is included.
